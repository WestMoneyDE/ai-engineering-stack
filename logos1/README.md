# LOGOS-1 integration layer

This directory is intentionally optional. It adds LOGOS-1 research/assurance primitives to the existing AI Engineering Stack without changing Hermes into an experimental cognitive architecture.

## Boundary

`Hermes state != model authority`  
`Agent memory != assurance state`  
`CPV != approval`  
`Research status != production permission`

The `GammaGate` example operates inside Node.js and therefore demonstrates **logical mediation only**. A production claim requires enforcement below the adaptive/runtime process.
